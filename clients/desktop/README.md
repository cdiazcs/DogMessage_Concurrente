# Cliente Swing

Compila con `python3 tools/build_desktop.py` o `py -3 tools/build_desktop.py`.
El JAR queda en `build/desktop/dog-messenger-desktop.jar`. El cliente usa TLS
con el almacén de confianza de Java y verifica el nombre del servidor.
Consulta los [comandos de arranque](../../docs/07_CLIENTES.md).
